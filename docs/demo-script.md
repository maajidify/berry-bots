Record at 1600×1000 or larger, browser zoom 90–100%. Run `npm run dev`, open http://localhost:5173.
Tip: start a fresh game (↺ NEW GAME) right before recording so the board starts empty; use 2× speed for the live parts.
Optional for the LLM cut: set `NEAR_AI_API_KEY` in `.env` so the roster shows `LLM` badges.
